| 字段 | 本镜记录 |
|---|---|
| scene_id / cue_id | 引用现有计划 |
| 本镜观众要理解什么 | 一句话 |
| 选用的组件 ID / 不使用理由 | 从 enrichment-catalog 选择，允许 none |
| 声音已说的内容、画面新增的信息 | 避免整段字幕再复制成图卡 |

| 字幕模式 | standard / speaker_aware / expressive_trial |
| 说话人、必要非语言声音 | 已核实标签或待核；不靠情绪模型猜测 |
| 静音时要保留的声音线索 | 角色、重音、停顿、笑声或回应；记录源音区间 |
| 表达型字幕的表现选择 | 拟声文字/有限强调/说明文字；角色色与身份线索、节奏、尺寸范围和退出方式；普通版保留同等必要信息 |

| 复用路线及缺口 | 必须读取 catalog 中的 adoption_status / gap |
| 退化方案 | 稳定普通字幕、静态标注、无音效等 |
| 必查证据 | 最长字、交接前后、手机尺寸、正常播放/静音检查 |
| 结果 | 待查/技术通过/人工通过分别填写，附当前候选哈希 |

录前便签：主题与两三点 → 本段起止句 → 要展示的页面/动作 → 预计补拍或易错处。

字幕纠错候选：原文、改后、源音区间、纠错类型、适用词域、反例、人工确认状态。识别纠错、删赘词和改写观点分别记录；不要把只删显示文本当作已剪掉原声。
