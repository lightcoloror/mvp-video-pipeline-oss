# 剪辑预设接入设计

2026-10-26，Codex（运行型号未另行核验）。依据用户本线程明确要求实施十类预设。

沿现有模块增加共享规则和验证函数；不替换 FFmpeg 出口、时间轴、素材库或编辑器路由。与单独检查报告相比，运行入口中的检查能够阻止未审核或已过期的编辑；与新建统一剪辑器相比，扩展现有入口维护成本更低。选择后者。

| 要求 | 接入位置 | 验收证据 |
| --- | --- | --- |
| 重录/重复 | spoken_rough_cut、video_use_edit_loop | 按用户补充：普通重录优先最后一遍候选；不完整/口误/质量问题/独有信息触发比较，缺复核记录时拒绝删除 |
| 首尾/反应 | 两条净剪入口、审阅窗口 | 已标记事件保留、未完成边界复核不能宣称验收、部分词截断拒绝 |
| 音频切口 | spoken_delivery 及增量音频滤镜 | 安全边界内淡化；时长不变；无安全余量则不自动处理 |
| 音量一致性 | production_strategy、audio_mastering | 显式用途/自定义目标；粗剪段落检查；最终输出重新测量 |
| 降噪 | speech_cleanup | 默认轻处理，强处理需试听证据；劣化反馈可回退 |
| 配乐 | music_pipeline | 复用优先窗口与慢释放，显式无配乐区间 |
| 字幕 | audio_timeline、字幕共用检查 | 语义断句候选、关键字完整、两行/字号/阅读检查，不缩字兜底 |
| 镜头/补充画面 | semantic_editorial | 事件触发和信息推进缺失时不能进入执行计划 |
| 转场/动效 | semantic_editorial、semantic_render_plan | 默认直接切；例外需理由；主要强调重叠检查 |
| 变速/时间轴 | video_use_context、投影及依赖合同 | 默认原速；速度例外需试听；编辑改变使字幕/音效/章节/进度及审核绑定失效 |

所有语义/声音质量结论来自显式审核记录，不能用检测值冒充听感；数值设为本项目预设而非普适标准。保持原始文件与旧合同可读，新工作使用更新策略；旧版本不能被静默重新解释为已通过新检查。

串行运行受影响单元测试和小型合成媒体测试，保留失败与最终证据。先验证本次实现，再逐项审计十项，不以少数绿色测试代替全部完成。
